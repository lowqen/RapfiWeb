## 4. relaxed SIMD 의 몫 — 대국에서 +58%, 무엇이 가르나

같은 Zenyth Web 의 두 변형 NPS — relaxed 66,037(본 매치) ↔ 일반 41,760(대조) = **×1.581**. 예전 측정은:

| 측정 | CPU | relaxed ↔ 일반 |
|---|---|---|
| B2 (`bench/gomocalc/results/ci-rx.*`) | AMD EPYC 9V74 · Chromium 151 | +19.6%(기하 평균 105.3K → 125.9K) |
| B1 | Intel Xeon 8370C | +23% |
| A3 (relaxed 에만 더해짐) | Intel Xeon 8573C · 재현 **8488C** | ×1.087 · 재현 ×1.112 |
| **이번 대국** | **Intel Xeon Platinum 8488C · Node 26** | **+58%** |

B2 의 2-a 와 이 기계의 A3 재현을 곱하면 +33% 남짓(1.196 × 1.112)이어야 하는데 그 두 배 가까이다. 두 수치는 **다른 런**(같은 기계,
연달아)에서 왔다. 처음 세운 가설은 「Sapphire Rapids(8488C)의 AVX-VNNI 가 relaxed i8 내적을 명령 하나로 낮춘다」였다.

### 4.1 같은 런 짝 측정 — AMD EPYC 7B13 (2026-10-07)

노드 고정 예열)로 국면마다 엔진 순서를 번갈아 짝지어 잼. 러너 AMD EPYC 7B13(Zen 3, nproc 4, CPU 플래그 **avx2 — VNNI 없음**).

- **A/A 가 0 을 품는다**(±2%) — 하네스를 믿을 수 있다. relaxed 는 짝 181개 중 165개에서 빨랐고, 트리가 다른 짝은 4개뿐(fmadd 반올림, 1부 H5).

### 4.2 같은 측정을 Intel Xeon Platinum 8488C 에서 (2026-10-07)

`variant-speed.yml` 런 **37619779632**(`expect_cpu=8488C` — 러너 CPU 확인, 기계 ip-10-192-17-128). CPU 플래그
**avx2 · avx512bw · avx512_vnni · avx_vnni**. 원자료 `bench/sprt/results/ci-37619779632-variant-speed-intel8488c.{json,md}`.

| relaxed ↔ 일반(같은 트리 짝) | **Intel 8488C (VNNI 있음)** | AMD 7B13 (VNNI 없음, §4.1) | Intel ÷ AMD (이득 몫) |
|---|---|---|---|
| A/A 대조 | +0.88% (−0.06 ~ +1.83) · 짝 198 | +0.25% (−1.89 ~ +2.45) | — |
| **전체** | **+57.02%** (+53.12 ~ +61.01) · 짝 176 | +32.47% (+28.56 ~ +36.51) | ×1.76 |
| 균형 개시 60 | **+77.01%** (+74.49 ~ +79.57) | +42.83% (+37.88 ~ +47.96) | ×1.80 |
| 필승 묶음 50 | **+32.58%** (+29.15 ~ +36.10) | +19.39% (+14.42 ~ +24.57) | ×1.68 |
| NPS(전체 합) simd → relaxed | 74,794 → **118,614** | 68,120 → 94,568 | |
| gomocalc ÷ simd 국면별 NPS 비 | 0.915 | 0.946 | |

- **두 CPU 의 구간이 겹치지 않는다** — relaxed 의 이득은 CPU 에 따라 확실히 다르고, 모든 국면 묶음에서 Intel 이 1.7 ~ 1.8배다.
  A/A 는 두 CPU 모두 ±2% 안(Intel 균형 개시 +1.3% 는 순서 효과 수준 — 이득 77% 에 비하면 무시할 크기).
- **VNNI 가설과 맞는다.** relaxed 의 i8 내적(`i32x4.relaxed_dot_i8x16_i7x16_add_s`)은 VNNI 가 있으면 `vpdpbusd` 한 명령으로,
  없으면 곱 · 합 여러 명령으로 낮춰진다. VNNI 가 있는 Intel 에서 이득이 크고, 없는 AMD 에서도 일반 SIMD 의 i8 내적 에뮬레이션
  (8명령, 1부 §2.2)보다는 짧아 +32% 가 난다 — 두 결과가 모두 설명된다. 다만 두 CPU 는 VNNI 말고도(AVX-512 · 마이크로아키텍처 · 클럭)
  다르므로 **인과는 확인이 아니라 정합**이다. 확정하려면 같은 계열에서 VNNI 만 다른 두 CPU(예: Zen 3 ↔ Zen 4)가 필요하다.
- 대국 중 NPS 비(§8.1, Zenyth Web relaxed ÷ gomocalc: Intel ×1.635 ↔ AMD ×1.372)도 같은 방향이다 — 짝 측정으로 계산한
  relaxed ÷ gomocalc 는 Intel 1.540 ÷ 0.915 = ×1.68 · AMD 1.337 ÷ 0.946 = ×1.41 로 대국 값과 가깝다.

**정리**: relaxed SIMD 의 이득은 **CPU 에 크게 달려 있다** — 개시 국면 기준 Intel 8488C(VNNI) +77% ↔ AMD 7B13 +43%. 그래서 본 매치의
Elo 우위도 CPU 를 따라 움직인다(Intel +100.2 ↔ AMD +77.2, §8). 큰 몫은 국면 종류가, 그 위의 배수는 CPU(VNNI 정합)가 정한다.

- 모든 대기(START → OK · RESTART → OK · 수 · YXSHOWFORBID)에 시간 제한 — 수는 수당 시간 + 유예. 넘으면 그 판은 진 것으로 하고 그 엔진을 갈아 끼운다.
- stdout · stderr 를 늘 끝까지 읽는다 — 우리가 기다리는 줄이 없을 때도. 파이프 버퍼가 차서 엔진이 write 에서 멈추는 데드락을 막는다(시험: 수마다 ~1MB 출력).
- stdin 은 역압(`drain`)을 따르고 그 기다림에도 시간 제한, EPIPE 는 프로세스 사망으로 처리.
- 끝낼 때 END → 유예 3초 → SIGKILL, 끝에서 남은 프로세스 · 파이프 핸들을 세어 0 이 아니면 종료 코드 1.
- 시간 예산을 넘으면 새 쌍을 시작하지 않고 시작한 쌍만 마저 둔다(잡 제한 전에 끝냄 — 이번 두 런이 이 경로로 끝났다).

`node --test bench/sprt/` 29/29(크래시 · 멈춤 · 불법 수 · 출력 폭주 · 시간 예산 · SPRT 결정 · 고정 판 수 · 탐색 통계).

### 9.3 읽는 법

| | 1 스레드 · Intel 8488C (§2) | 1 스레드 · AMD 7B13 (§8) | **2 스레드 · Intel 8581C (§9)** |

- **남는 +26% NPS** 는 relaxed 경로 위의 우리 쪽 개선이다 — A3 배치(relaxed 에서만, 8488C 재현 +11.2%) · A1 · upstream 의 NNUE 추론 가속
  (`2a773f1b` — 행렬곱 인라인 · 그룹 합). 같은 ISA 일반 SIMD 대조(§2, ×1.047)보다 훨씬 크다 — relaxed 경로에서 우리 개선이 더 많이 쌓였다.

  가를 수는 없지만, 「upstream 1년 + 패치가 같은 속도에서 더 잘 둔다」는 몫은 **없다**(§2 대조와도 같은 결론).

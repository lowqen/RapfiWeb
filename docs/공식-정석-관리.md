# 공식 정석 커리큘럼 관리 (관리자용)

공식 커리큘럼은 저장소의 정적 파일 **`public/joseki/curriculum.json`** 하나다. 모든 사용자는 정석 ▸ [공식 커리큘럼]
에서 읽기 전용으로 배우고, 관리자는 이 파일을 바꿔 커밋하는 것으로 배포한다. 설계와 데이터 구조는
[`공식-정석-설계.md`](공식-정석-설계.md).

## 레슨 하나를 만들어 싣기

1. **관리자 도구 켜기** — 설정 ▸ 고급 설정 켬 ▸ 시스템 ▸ «관리자 도구». (보안 장치가 아니다. 켜면 편집기에
   내보내기 단추가 보일 뿐이고, 배포 권한은 저장소 쓰기 권한이다.)
2. **트리 쓰기** — 정석 ▸ [내 정석] ▸ 새 정석. 판이나 글(`h8 i9 j10`)로 수를 넣고, 마디마다:
   - 해설(마크다운 — 굵게 · 기울임 · 목록 · 링크, `h8` 같은 좌표는 누르면 그 수로)
   - **주 변화가 추천 수**다(`[0]`) — 「주 변화로」 단추로 올린다.
   - 평가 기호: `!!` `!` `!?` 는 학습에서 «다른 좋은 수»(정답으로 받음), `?!` `?` `??` 는 «나쁜 수»(오답 — 해설을 보임).
   - 갈래 쓰임: **함정수**(그럴듯하지만 걸려드는 수 — 학습에서 오답), **응징**(나쁜 수 · 함정을 벌하는 답 — 나쁜 수
     마디의 첫 자식으로 두면 학습의 오답 화면에 «응징: …»으로 나온다).
3. **내보내기** — 편집기 위의 «공식 커리큘럼으로 내보내기»: 코스(있는 코스 또는 새 코스 — id 는 영문 소문자 · 숫자 ·
   `-`), 수준, 레슨 id · 제목 · 요약, 학습자 색(학습 모드에서 사용자가 둘 색)을 정하고 «curriculum.json 내려받기».
   지금 배포된 커리큘럼에 그 레슨을 넣거나(같은 id 면 바꾸거나) 한 **파일 전체**가 내려받아진다. 내려받기 전에 앱과
   같은 검증을 거쳐 경고가 있으면 알려 준다.
4. **저장소에 싣기**
   ```bash
   cp ~/Downloads/curriculum.json public/joseki/curriculum.json
   pnpm test        # 배포 파일 검증 · 26주형 이름 대조 · 영어 누락 검사
   git add public/joseki/curriculum.json
   git commit -m "docs: add <lesson> to curriculum"
   git push         # CI → Cloudflare Pages
   ```
5. **영어** — 내보낸 해설은 한국어 글이다. 영어 화면에서도 읽히게 하려면 JSON 에서 글을 `{ "ko": "…", "en": "…" }` 로
   바꾼다. `pnpm test` 의 «모든 해설에 영어가 있다» 시험이 빠진 곳을 짚는다(배포 파일 기준).

## 검증이 막는 것

`src/core/curriculum/curriculum.test.ts` 가 배포 파일을 매번 읽는다.

| 시험 | 막는 것 |
|---|---|
| 검증을 문제 없이 통과 | 판 밖 · 겹친 수 · 모르는 기호 · 잘못된 id · 학습자가 둘 수가 없는 레슨 |
| 26주형 이름 대조 | 해설이 «화월(D4)» 처럼 말한 이름이 그 마디까지의 수순(3수 이상)과 다를 때 |
| 영어 누락 | 영어 화면에 한글이 새는 글 |

## 레슨 링크

레슨마다 주소가 있다 — `https://rapfiweb.pages.dev/joseki?lesson=<레슨 id>`, 학습으로 바로 열려면 `&mode=learn`.
레슨 화면의 «링크 복사»가 지금 레슨 · 모드의 주소를 클립보드에 넣는다. 공지 · 강의 자료에 이 주소를 걸면 된다.
없는 id 면 앱이 알리고 코스 목록을 보인다. **id 를 바꾸면 옛 링크가 끊긴다** — 진도와 같은 까닭으로 id 는 그대로 둔다.

## 진도

학습 점수(첫 시도 정답률)와 완료 횟수는 사용자 브라우저의 `localStorage`(`rapfi.curriculum.progress`)에 레슨 id 를
열쇠로 남는다. **레슨 id 를 바꾸면 그 레슨의 진도는 새로 시작한다** — 고칠 때는 id 를 그대로 두고 내용만 바꾼다.

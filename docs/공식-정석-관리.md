# 공식 정석 커리큘럼 관리 (관리자용)

공식 커리큘럼은 저장소의 정적 파일 **`public/joseki/curriculum.json`** 하나다. 웹(RapfiWeb)과 앱(Zenyth)이
**같은 파일**을 읽는다 — 웹은 같은 출처의 자산으로, 앱은 `https://rapfiweb.pages.dev/joseki/curriculum.json` 을 받아
(오프라인이면 마지막으로 받은 것, 처음이면 APK 에 든 사본). 그래서 관리자가 이 파일 하나를 고쳐 배포하면 두 곳이 함께
바뀐다. 설계와 데이터 구조는 [`공식-정석-설계.md`](공식-정석-설계.md).

만드는 곳은 **커리큘럼 스튜디오**(`/joseki/studio`), 싣는 것은 **`pnpm curriculum:publish`** 한 줄이다.

## 한 번에 보기

```bash
pnpm studio                  # 개발 서버 + 스튜디오가 열린다(관리자 도구 켜기 → 고치기 → «저장소에 저장»)
pnpm curriculum:publish      # 검사 · 시험 · 커밋 · push → 몇 분 뒤 웹과 앱에 반영
```

배포된 사이트(rapfiweb.pages.dev)에서 고쳤다면 «curriculum.json 내려받기» 뒤
`pnpm curriculum:publish ~/Downloads/curriculum.json`.

## 1. 스튜디오 열기

- **`pnpm studio`**(권장) — 개발 서버를 띄우고 `/joseki/studio` 를 연다. 이때만 «저장소에 저장» 단추가 있어,
  고친 커리큘럼을 `public/joseki/curriculum.json` 에 바로 쓴다(`scripts/studio-plugin.ts`, 이 컴퓨터에서 온 요청만).
- 어디서나 — 설정 ▸ 고급 설정 켬 ▸ 시스템 ▸ «관리자 도구»를 켜면 정석 ▸ 공식 커리큘럼에 «커리큘럼 편집»이 생긴다.
  배포된 사이트에는 저장소 쓰기 길이 없으므로 파일로 내려받는다.

«관리자 도구»는 **보안 장치가 아니다** — 누구나 켤 수 있고, 켜서 할 수 있는 일은 자기 브라우저의 초안을 고치고 파일을
내려받는 것까지다. 배포의 경계는 저장소 쓰기 권한(git)이다.

## 2. 스튜디오에서 만들기

화면은 왼쪽 **목록**(개요 · 코스 › 레슨, 오류가 있는 곳에 빨간 점), 오른쪽 **편집기**다.

| 하는 일 | 방법 |
|---|---|
| 코스 만들기 | 목록 아래 «코스 추가» → id · 제목(한/영) · 수준 · 설명(한/영) |
| 레슨 만들기 | 코스의 «레슨 추가», 목록의 «+ 레슨», 또는 «내 정석에서 가져오기» |
| 내 정석을 레슨으로 | 정석 ▸ 내 정석 편집기의 «공식 커리큘럼 레슨으로» → 넣을 코스 고르기 |
| 차례 바꾸기 | 코스 · 레슨 편집기의 «위로» · «아래로», 레슨의 «코스»에서 다른 코스로 옮기기 |
| 사본 · 지우기 | «사본 만들기», «레슨 지우기»(한 번 더 눌러야 지운다) |
| 수 넣기 | 판을 누르거나 `h8 i9 j10` 을 적어 «넣기», 보드 탭에 놓은 수순은 «보드의 수순 넣기» |
| 갈래 | 같은 마디에서 다른 수를 두면 갈래. «주 변화로» · «갈래 앞으로/뒤로» · «이 수부터 지우기» |
| 해설 | 마디마다 한국어 · 영어 두 칸(마크다운 — 굵게 · 기울임 · 목록 · 링크, `h8` 같은 좌표는 누르면 그 수로). «한국어/영어 미리 보기» |
| 되돌리기 | «되돌리기» · «다시 하기»(Ctrl+Z · Ctrl+Shift+Z), 50번까지 |
| 미리 보기 | 레슨의 «미리 보기» — 배포했을 때의 살펴보기 · 학습 화면 그대로(진도는 남지 않는다) |

**학습 판정의 규칙** — 트리에 어떻게 두느냐가 곧 문제다.

- **주 변화(맨 앞 갈래 `[0]`)가 추천 수**다. 학습자는 그 수를 맞혀야 하고, 상대 수는 저절로 둔다.
- 평가 기호 `!!` `!` `!?` 는 «다른 좋은 수»(정답으로 받고 그 갈래로 간다), `?!` `?` `??` 는 «나쁜 수»(오답 — 해설을 보인다).
- 갈래 쓰임 **함정수**는 그럴듯하지만 걸려드는 수(학습에서 오답), **응징**은 나쁜 수 · 함정을 벌하는 답 — 나쁜 수
  마디의 첫 자식으로 두면 오답 화면에 «응징: …»으로 나온다.
- 판 위의 줄 «다음은 학습자 차례 / 상대 차례»가 지금 마디의 자식이 문제인지 알려 준다. 학습자 색은 레슨의 «학습자».

**초안** — 고칠 때마다 이 브라우저(`localStorage`)에 저절로 남는다. 창을 닫았다 열어도 이어서 고치고, «배포본으로
되돌리기»가 초안을 버린다(되돌리기로 다시 살릴 수 있다). 머리의 «배포본과 같음/다름»이 지금 상태다.

## 3. 검사 — 오류가 0 이어야 싣는다

머리의 «오류 · 경고» 단추(개요)와 편집기마다의 «검사» 칸. 줄을 누르면 그 코스 · 레슨 · 마디로 간다. **스튜디오,
`pnpm curriculum:publish`, 배포 파일 단위 시험이 같은 함수(`core/curriculum/audit.ts`)를 쓴다** — 스튜디오에서
오류가 0 이면 시험도 통과한다.

| 수준 | 짚는 것 |
|---|---|
| 오류 | 코스가 없음 · 레슨 없는 코스 · 잘못되었거나 겹친 id · 학습자가 둘 수가 주 변화에 없는 레슨(앱이 버린다) |
| 오류 | 해설이 «화월(D4)» 처럼 말한 26주형 이름이 그 마디까지의 수순(3수 이상)과 다름 |
| 오류 | **영어 없음** — 코스 제목 · 설명, 레슨 제목 · 요약, 해설. 영어 화면에 한글이 새지 않게 |
| 경고 | 배포본에 있던 코스 · 레슨이 사라짐(id 를 바꾼 것도 같다) — 그 링크와 사용자의 진도가 끊긴다 |
| 경고 | 빈 제목 · 주 변화에 나쁜 수나 함정수(학습이 그것을 정답으로 가르친다) · 수가 너무 많은 레슨 |

## 4. 싣기 — `pnpm curriculum:publish`

```bash
pnpm curriculum:publish                          # «저장소에 저장»으로 쓴 파일을
pnpm curriculum:publish ~/Downloads/curriculum.json   # 내려받은 파일을
pnpm curriculum:publish --dry-run                # 검사만
pnpm curriculum:publish --no-push                # 커밋까지만
```

하는 일: ① 앱과 같은 규칙으로 검증하고 지금 커밋된 배포본에 견줘 검사(오류가 있으면 멈춤, 경고는 보이고 지나감)
→ ② 배포 글꼴로 `public/joseki/curriculum.json` 에 씀(`core/curriculum/format.ts` — 누가 어디서 고쳐도 같은 내용이면
같은 바이트) → ③ 커리큘럼 단위 시험 → ④ **그 파일 하나만** 커밋(`docs: curriculum <버전>`, 본문에 더한 · 뺀 · 고친
레슨) → ⑤ push. main 의 push 가 Cloudflare Pages 배포(deploy.yml)를 부른다.

버전은 내보낼 때 저절로 붙는다 — 그날 처음이면 `2026.10.11`, 같은 날 또 내면 `2026.10.11.2`, `.3` …

## 5. 웹과 앱에 닿기

- **웹**: 배포가 끝나면(몇 분) 정석 ▸ 공식 커리큘럼이 새 파일을 읽는다.
- **Zenyth 앱**: 정석 탭을 열 때 `rapfiweb.pages.dev/joseki/curriculum.json` 을 받아 기기에 둔다(바뀌지 않았으면
  내려받지 않는다 — ETag, 10분에 한 번까지). 오프라인이면 마지막으로 받은 것, 처음 설치 직후 오프라인이면 APK 에 든
  사본을 쓴다. 정석 탭의 커리큘럼 머리에 지금 버전과 «RapfiWeb 과 같음»이 보인다. 사용자가 설정 ▸ «정석 커리큘럼
  자동 업데이트»를 끄면 새로 고침 단추를 누를 때만 받는다. APK 의 사본은 릴리스 때 Zenyth 의
  `tools/sync_curriculum.sh` 로 맞춘다(앱은 그 사본보다 받은 파일을 먼저 쓴다).
- 레슨 링크 `https://rapfiweb.pages.dev/joseki?lesson=<id>`(학습은 `&mode=learn`) · 코스 링크 `…?course=<id>` 는
  웹에서도, 앱이 깔린 안드로이드에서는 앱에서도 그 레슨 · 코스로 열린다. 공지 · 강의 자료에 이 주소를 건다.

## 6. id 와 진도

학습 점수(첫 시도 정답률)와 완료 횟수는 사용자 기기(웹은 `localStorage` 의 `rapfi.curriculum.progress`, 앱은 기기
저장소)에 **레슨 id** 를 열쇠로 남는다. 레슨 링크도 id 다. **배포한 레슨의 id 는 바꾸지 않는다** — 고칠 때는 id 를
그대로 두고 내용만 바꾼다. 스튜디오는 id 칸 옆에 이것을 적어 두었고, 사라지는 id 는 검사가 경고한다.

## 손으로 고칠 때

JSON 을 직접 고쳐도 된다 — 글은 `"…"` (한국어만) 또는 `{ "ko": "…", "en": "…" }`. 고친 뒤
`pnpm curriculum:publish` 가 검사 · 글꼴 맞추기 · 시험 · 커밋을 똑같이 한다.

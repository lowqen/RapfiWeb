## 0. Brand Philosophy

### Core Values

1. **판이 주인공** — 화면을 연 사람이 가장 먼저 보는 것은 오목판이다. 나머지는 판을 거든다.
2. **1초 안에 둔다** — 설명을 읽지 않아도 누르면 돌이 놓이고, 누르면 엔진이 읽는다.
3. **필요할 때만 펼친다** — 엔진 수치 · 예산 · 파일 형식 같은 전문 기능은 접혀 있다가 부를 때 나온다.

### Tone of Voice

짧은 평서문. 화면 문구는 «무엇을 하는지»만 말하고 «왜 그런지»는 툴팁이나 펼침 안에 둔다.
한 카드의 안내는 한 줄을 넘기지 않는다. 대시(— · –)를 쓰지 않는다(i18n 시험 규칙).

### Design Principles

1. **One primary action per card** — 카드마다 채운 버튼은 하나(분석 · 지금 판 리뷰 · 지금 판 증명).
2. **Progressive Disclosure** — 설정 묶음은 `Disclosure`(접힘 + 한 줄 요약)로. 펼친 상태는 기억한다.
3. **Empty states say one thing** — 값이 없을 때 «없음» 타일을 늘어놓지 않고 다음 행동 한 줄을 보인다.
4. **Calm surfaces** — 흰 카드 + 머리카락 테두리. 면 위에 면을 겹치지 않는다.

| 철학 | 디자인 결정 |
|---|---|
| 판이 주인공 | 상단 바 한 줄(부제 삭제) · 오프닝 화면도 판 왼쪽 + 정보 오른쪽 2단 |
| 1초 안에 둔다 | 엔진 칩은 상태 낱말만, 변형 이름은 툴팁 |
| 필요할 때만 | 분석 설정 · 리뷰 설정 · 증명 설정 · DB 옵션 · 엔진 세부 수치를 펼침으로 |

## 1. Visual Theme & Atmosphere

따뜻한 종이색 캔버스 위에 흰 카드가 조용히 놓이고, 나무색 판이 화면의 무게중심을 잡는다.
강조는 초록 한 가지(선택 · 주 행동), 경고는 붉은 갈색. 숫자는 고정폭 숫자로 흔들리지 않는다.

## 2. Color Palette & Roles

팔레트 값은 바꾸지 않는다 — `src/core/design/ramps.ts` 가 안드로이드 앱과 같은 값을 골든 시험으로 지킨다.
바뀐 것은 **역할의 배정**뿐이다.

| 이름 | 토큰 | 역할 |
|---|---|---|
| Canvas | `--c-background` (#FCF9F4 / #221F1C) | 페이지 배경 |
| Card | `--c-card` = light-dark(surface-container-lowest, surface-container) | 카드 면(새 별칭) |
| Hairline | `--c-outline-variant` | 카드 테두리 · 구분선 |
| Ink | `--c-on-surface` (#262320) | 본문 (Pure Black 아님) |
| Mute | `--c-on-surface-variant` | 보조 글 · 요약 |
| Accent | `--c-secondary-container` / `--c-on-secondary-container` | 선택 · 주 행동 (단일 액센트) |
| Primary ink | `--c-primary` | «지금 해야 할 한 가지» 채운 버튼 |
| Danger | `--c-error` | 지우기 · 멈추기 |

## 3. Typography Rules

- Family: `"Pretendard Variable", Pretendard, system-ui, sans-serif` — 저장소 안에서 내보낸다(`pretendard` npm,
  동적 서브셋 woff2, OFL-1.1). CSP `font-src 'self'` 와 COEP 아래서도 그대로 뜬다.
- 크기 스케일은 15슬롯 그대로(`tokens.ts`). 위계는 크기보다 굵기가 진다.
- 한국어: `word-break: keep-all` 전역, 본문 줄높이는 토큰 값(20/14 ≈ 1.43)에 더해 안내 문단만 1.6.
- 영문 대문자 지표(DEPTH · EVAL …)는 화면에서 걷어 내고 «승률 · 평가 · 깊이»로 말한다.

## 4. Component Stylings

**Card (`.panel`)** — Card 면 · 1px Hairline · radius-l · padding 16. 그림자 없음.

**Disclosure (`components/Disclosure.tsx`)**
- Default: 제목(왼쪽) · 요약(오른쪽, Mute) · 꺾쇠. 한 줄 전체가 버튼.
- Hover: 면이 surface-container 로 한 단. Focus: 2px primary outline. Active: 꺾쇠 90° 회전.
- Open 상태는 `localStorage("rapfi.open.<id>")` 에 남는다.
- 닫힌 내용은 DOM 에 남고 `hidden` — 값을 읽는 시험과 화면 낭독기의 이름 계산이 흔들리지 않는다.

**Buttons** — 주 행동 1개만 채움(primary 또는 tonal), 나머지는 윤곽. Disabled 는 글자와 테두리를 함께 죽인다.

**Empty state** — 한 줄 안내 + (있으면) 행동 버튼 하나.

## 5. Layout Principles

- 셸: 레일(주 항목 셋 위 · 도구 셋 아래로 떨어뜨림) + 한 줄 상단 바 + 내용.
- 보드: 판 + 옆 칸(국면 → 엔진 → 형세 → 분석 설정). 옆 칸 카드는 넷 그대로.
- 오프닝: 넓은 화면(≥1024px)에서 판 왼쪽 · 정보 오른쪽 2단.
- 연구 ▸ 리뷰: 행동 카드가 맨 위, 설정은 그 안의 펼침, 증명은 맨 아래의 펼침 카드.
- 읽기 폭: 단일 열 화면은 `--reading-width`(640px) 기준 가운데.

## 6. Depth & Elevation

카드는 그림자 없이 테두리로만. 떠 있는 것(레일 서브메뉴 · 확인 상자)만 `0 4px 16px rgb(0 0 0 / .12)`.

## 7. Motion & Interaction

`Motion.kt` 의 네 규칙을 그대로: 미끄러지지 않는다 · 200ms 이하 · 실시간 숫자는 보간하지 않는다 · 하트비트 500ms.
펼침은 fade-in(150ms)만. `prefers-reduced-motion` 은 기존 전역 규칙이 진다.

## 8. Responsive Behavior

- <640px: 하단 탭 6, 옆 칸은 판 아래. 펼침 머리는 44px 이상.
- 640–1024px: 레일 + 1열.
- ≥1024px: 보드 · 오프닝 2단.

## 9. Anti-Patterns (이 프로젝트에서 금지)

- 화면 위에 «이 기능은 무엇이고 왜 이렇게 동작하는지» 문단을 늘 펼쳐 두기 → 한 줄 + 툴팁/펼침
- 값이 없는 지표 타일을 «없음»으로 여러 칸 채우기 → 빈 상태 한 줄
- 엔진 내부 이름(multi-simd128-relaxed · YXNBEST · AND/OR)을 첫 화면 글로 → 툴팁
- 카드 안에 회색 면을 또 깔기(면 위의 면)
- 한 카드에 채운 버튼 둘 이상
- 팔레트 hex 를 base.css 에 직접 쓰기 → 토큰만
